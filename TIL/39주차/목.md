## std::move

### lvalue/rvalue

lvalue는 이름이 있고 메모리 어딘가에 계속 존재해서 접근할 수 있는값이다.
rvalue는 이름이 없고, 잠깐 만들어졌다가 금세 사라질 임시 값
둘을 나누는 이유는 복사할지, 자원을 뺏어와도 될지 판단하기 위함

일반적인 lvalue를

```c++
std::string a = "엄청나게 긴 문자열...";
std::string b = a;
```

이렇게 대입하면 C++에서 자동으로 복사가 됨
string의 경우 복사 생성자가 string(cosnt string& other); 이런식으로 되어있음

rvalue를

```c++
std::string b = std::string("hello");
```

오른쪽의 임시 string은 어차피 이 줄이 끝나면 사라짐
그냥 임시 객체가 가지고 있던 데이터를 b로 이동하면 됨 이게 move
이때 호출되는 생성자가 string(string&& other);

### move constructor / move assignment operator / copy constructor

move constructor는

```c++
std::string a = "hello";
std::string b = std::move(a);
```

새객체를 만드는 중일때 사용, 여기서 b는 새로 생성되는 중임
그래서 호출되는건 string(string&& other);

move assignment operator는

```c++
std::string a = "hello";
std::string b = "world";

b = std::move(a);
```

여기서 b는 이미 존재함, 새 객체를 만드는게 아니라 기존 b에 값을 넣는 것
string& operator=(string&& other)가 됨

copy constructor는

```c++
std::string a = "hello";

std::string b = a; // copy constructor
// string(const string& other);
```

C++에서 T&는 lvalue reference, T&&는 rvalue reference라고 함

### 그래서 move왜씀?

더 이상 필요없는 객체가 가진 자원을 새 객체가 재사용해서, 비싼 복사를 피하기 위해서
만약 a에서 b로 데이터를 옮기는데 그냥 옮기면 복사가 일어나는데, a가 더이상 필요 없는경우 move를 통해서 옮기면 a는 비어있게되고 b에는 데이터가 차게 됨
허나 여기서 중요한게 move는 본질적으로 실제로 데이터를 옮기는건 아니다.
std::move(a)하면 a를 rvalue처럼 취급하도록 변환한다는 의미 (더 정확하게는 xvalue라고 한다)

```
std::string b = std::move(a);
a
↓
std::move(a)
↓
"a를 이동 가능한 값으로 취급"
↓
Move Constructor 선택
↓
string(string&& other)
↓
실제로 a의 자원을 b가 가져감
```

여기서 만약 새객체면 move constructor가 기존 객체면 move assignment operator가 호출

```c++
std::string a = "hello";
std::string b = std::move(a);
// 여기서는 string(string&& other) -> move constructor

std::string c = "hello";
std::string d = "world";
d = std::move(c);
// 여기서는 d가 이미 있기때문에 string& operator=(string&& ohter); 즉 move Assignment operator가 호출
```

## const

const의 경우 약간 상수처럼 사용하겠다 그런 선언
const 함수의 의미는 `이 함수는 객체 상태를 변경하지 않겠다` 라는 뜻
const 객체는 일반적으로 const함수만 호출할 수 있음, non-const 멤버 함수는 객체를 수정할 수도 있으니까 const 객체에서는 호출을 막음

```c++
int a = 10;
int b = 20;
const int* p = &a;

p = &b; // O
// *p = 30; // X
```

pointer to const -> p가 가리키는 값 수정 x, p자체가 다른 주소를 가리키는 건 O

```c++
int* const p = &a;
```

이거는 const pointer -> p가 가리키는 값 수정 O, p가 저장한 주소 변경 X
const int\* const p; -> 이렇게도 가능함 둘다 const, const오른쪽에 뭐가 있는지를 보면 간단함
