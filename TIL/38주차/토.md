## 3강

- Swap Chain: 뒤 버퍼에 그린 뒤 화면 앞 버퍼로 교체하는 구조
- Device / Device Context: GPU 리소스를 만들고, 그리기 명령을 실행하는 객체
- Render Target / Depth Buffer: 색을 그릴 대상과 앞뒤 깊이 판정용 버퍼
- BeginScene / EndScene: 화면 지우기와 화면 표시(Present)의 시작·끝
- Projection Matrix / Viewport: 3D 장면을 화면 좌표로 보이게 만드는 과정

## 4강

- Vertex Buffer / Index Buffer: 삼각형 정점 데이터와 그리는 순서를 GPU에 전달하는 버퍼
- Vertex Shader / Pixel Shader: 정점 위치를 변환하고, 최종 픽셀 색을 계산하는 GPU 프로그램
- HLSL: DirectX 셰이더 언어
- Input Layout: C++의 정점 구조체와 HLSL 입력(POSITION, COLOR)을 연결하는 규칙
- World · View · Projection 행렬: 모델 위치 → 카메라 기준 → 화면 투영 변환
- Constant Buffer: 매 프레임 바뀌는 행렬 같은 데이터를 셰이더로 전달하는 버퍼
- DrawIndexed: 인덱스 버퍼 기준으로 GPU에 실제 그리기를 요청하는 호출
