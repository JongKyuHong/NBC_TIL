## 인런 파츠 구현

PlayerState에 붙는 PartEquipComponent에 인런 상점용 로직들을 넣어놓음, 어차피 개인으로 독립적으로 동작하기 때문에 넣어놓았고, PlayerState에서 스테이지 넝머갈때 CopyProperties에서 인런 상점 관련된 내용은 넘기지않아서 스테이지별로 독립적으로 존재하는 상점으로서 존재가 가능하다.

## PartCatalogEntryWidget

현재 파츠 카드 위젯은 인런, 아웃런상점에서 둘다 사용하고 있는 구조이다.
아웃런 : SetupEntry(Row, OwnerWidget) : 클릭시 OwnerWidget->SelectCatalogPart(...)호출
인런 : SetupEntry(Row, ClickHandler) : 클릭시 델리게이트 호출

두곳에서 다른방식으로 초기화됨

클릭 처리 함수(OnSelectButtonClicked)는 이 순서로 판단

```c++
if (ClickHandler.IsBound())
{
    ClickHandler.Execute(...);   // 인런 경로
    return;
}
```

ClickHandler.Unbind()를 명시적으로 호출하면 인런에서 호출 -> 아웃런에서 호출할때 바인딩을 끊어서 아웃런에서도 정상동작하게끔

같은 이유로 AddUniqueDynamic으로 바꾼이유도 같은 카드위젯을 재사용하는 구조로 변경되어서 AddDynamic을 쓰면 다시 호출할때마다 델리게이트가 쌓인다. (실제로 발생하지는 않고 있지만 나중에 위젯풀링으로 변경되거나 하면 방어코드가 됨)
