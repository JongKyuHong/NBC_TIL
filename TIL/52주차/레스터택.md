# BitmapClass

이미지의 위치, 크기, 정점, 인덱스 버퍼와 텍스처를 관리

# 화면 좌표 계산

(150, 80) 같은 왼쪽 위 기준 위치를 실제 사각형 정점 좌표로 변환

# 동적 VB

위치나 크기가 바뀌면 기존 정점 버퍼의 내용을 갱신

# 직교 투영 + 깊이 테스트 끄기

거리 때문에 크기가 달라지지 않게 그리고, 깊이 비교 없이 표시한 뒤 상태 복원

# HLSL

GPU에서 실행할 셰이더 코드를 작성하는 언어, High-Level-Shading-Language
DirectX에서 아용, texture.vs, texture.ps가 HLSL코드

# 튜토리얼 13

## 학습 목표

1. 스프라이트(여러 이미지 순환)의 개념
2. 고정밀 타이머로 프레임 간 시간 측정
3. 프레임 시간 기반의 애니메이션(프레임률 독립)
4. 데이터 주도 설계(텍스트 파일로 제어)

## 배운점

델타 타임을 누적해서 이미지를 교체하는 방식을 배웠습니다.
txt파일에서 기준 시간 250을 500으로 바꿔서 업데이트 주기를 늦춰보았습니다.

## 어려웠던점

- ApplicationClass와 SpriteClass의 흐름 이해가 어려웠습니다.
  ApplicationClass::Frame에서 현재 프레임 시간을 SpriteClass::Update로 넘김, txt파일에 설정된 시간이 지났다면 다음 이미지를 가리키도록 함
  ApplicationClass::Render에서 SpriteClass::Render를 호출해 정점, 인덱스버퍼를 갱신하고 텍스처 셰이더에 전달해 렌더링
  ApplicationClass::Frame -> SpriteClass::Update -> ApplicationClass::Render -> SpriteClass::Render
