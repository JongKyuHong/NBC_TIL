# Trie

문자열을 한 글자씩 트리에 저장하면서, 공통된 접두사(Prefix)를 공유하는 자료구조
문자열 검색, 자동 완성 기능을 구현할때 사용한다.

## Trie는 왜 필요할까?

```c++
["apple", "app"]

unordered_set<string> words;

words.insert("apple");
words.insert("app");
```

apple, app이라는 단어를 저장한다고 하자.
apple, app이라는 단어가 정확히 존재하는지 확인은 us으로도 가능하다 하지만
ap로 시작하는 단어가 하나라도 존재하는지 확인하려면 us로는 한계가 있다.
Trie는 단어 자체뿐 아니라 `접두사도 효율적으로 확인할 수 있도록 문자열을 트리 형태로 저장`함

## 어떤구조일까?

```
root -> a -> p -> p -> l -> e
```

apple을 저장하면 이런 경로로 저장이 된다.
이제 app을 추가하면 이미 a -> p -> p라는 경로가 존재하므로 노드를 새로 만들지 않는다. 대신 두 번째 p노드에 `app`이라는 단어가 여기서 끝난다는 표시를 추가한다.

여기서 특징은

1. 공통 접두사 공유 : app공유
2. 단어의 끝 표시 : 어떤 위치까지의 경로가 실제 저장된 단어인지 구분

## C++에서 노드를 어떻게 만들까?

각 노드는 다음 정보를 가지고 있으면 된다.

```c++
struct Node {
    Node* children[26] = {};
    bool isEnd = false;
};
```

children[26] : 다음 문자로 연결되는 자식 노드 (a ~ z)
isEnd : 현재 위치가 저장된 단어의 끝인지 표시

## 세 가지 기능의 작동 원리

### insert("apple")

루트에서 시작해서 단어를 한글자씩 확인

| 처리 문자 | 현재 노드      | 확인하는 대상                     | 결과          |
| --------- | -------------- | --------------------------------- | ------------- |
| a         | root           | root 바로 아래에 a가 있는가?      | 없으므로 생성 |
| 첫 번째 p | a 노드         | a 바로 아래에 p가 있는가?         | 없으므로 생성 |
| 두 번째 p | 첫 번째 p 노드 | 첫 번째 p 바로 아래에 p가 있는가? | 없으므로 생성 |
| l         | 두 번째 p 노드 | 두 번째 p 바로 아래에 l이 있는가? | 없으므로 생성 |
| e         | l 노드         | l 바로 아래에 e가 있는가?         | 없으므로 생성 |

e에서는 isEnd = true

### search("app")

a -> p -> p 경로를 따라가면 모든 문자가 존재하지만 아직 app은 삽입하지 않았으므로 p의 isEnd는 false
따라서 search("app")은 false를 반환한다.
경로가 존재하는 것과 단어 자체가 저장되어 있는 것은 다른 조건이다.

### startsWith("app")

완전한 단어인지 확인할 필요가 없다.
a -> p -> p 경로가 존재한다면 그 접두사로 시작하는 단어가 있다는 뜻
따라서 startsWith("app")은 true

## 연습문제

https://leetcode.com/problems/implement-trie-prefix-tree/?utm_source=chatgpt.com

208. Implement Trie (Prefix Tree)

```c++

class Trie {
private:
    struct Node{
        int children[26] = {};
        bool isEnd = false;
    };

    vector<Node> nodes;

    int findNodes(const string& word){
        int current = 0;
        for (char c : word){
            int index = c - 'a';
            if (nodes[current].children[index] == 0){
                return -1;
            }
            current = nodes[current].children[index];
        }
        return current;
    }

public:
    Trie() {
        nodes.emplace_back();
    }

    void insert(string word) {
        int current = 0;
        for (char c : word){
            int index = c - 'a';
            if (nodes[current].children[index] == 0){
                int newIndex = nodes.size();
                nodes[current].children[index] = newIndex;
                nodes.emplace_back();
            }
            current = nodes[current].children[index];
        }
        nodes[current].isEnd = true;
    }

    bool search(string word) {
        int value = findNodes(word);
        return value != -1 && nodes[value].isEnd == true;
    }

    bool startsWith(string prefix) {
        int value = findNodes(prefix);
        return value != -1;
    }
};

```
