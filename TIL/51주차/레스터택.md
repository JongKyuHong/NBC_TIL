# 튜토 12번

## 큰 그림

2D이미지는 사실 쿼드(사각형) 폴리곤에 텍스처를 입혀, 3D 투영 대신 직교 투영으로 그린 것
UI/스프라이트/폰트가 모두 이 위에 세워짐
-> 화면에 사각형을 하나 그리고, 그 사각형 안을 이미지로 채운다.

### 3D투영과 직교 투영 차이

여기서 말하는 3D투영은 원근 투영을 뜻한다.

- 원근 투영(Perspective)
  같은 크기의 상자라도 가까우면 크게, 멀면 작게 보임. 게임에서 카메라로 3D장면을 볼때 주로 쓴다.

- 직교 투영(Orthographic)
  같은 크기의 상자라면 카메라에서 멀어져도 화면 속 크기가 그대로
  화면에 버튼이나 아이콘을 일정한 크기로 그릴때 쓴다.

## 2D렌더흐름

1. 2D 좌표계산
   화면 크기와 렌더 위치로 쿼드 네변을 계산
2. 동적 VB갱신
   위치가 바뀐 프레임에만 정점을 동적 버퍼에 다시 씀
3. Z버퍼 끄기
   깊이 무시하고 덮어 그리도록 Z버퍼를 끔
4. ortho 렌더
   직교 행렬로 화면 좌표에 텍스처 쿼드를 그림
5. Z버퍼 켜기
   2D끝 다음 3D렌더를 위해 다시 켬

배운 점

- 2D렌더흐름을 배웠다.
- 직교 투영과 3D투영의 차이점에 대해서 알게 되었다.
- m_Bitmap->Initialize에서 좌표를 수정해 위치를 수정해보았다.
- 비트맵 크기를 변경해보았다.
