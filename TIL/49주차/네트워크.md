# 서브넷 마스크

IP주소에서 어디까지가 네트워크 주소이고, 어디부터가 기기(호스트)를 구분하는 주소인지 알려줌

```
IP 주소       192.168.0.10
서브넷 마스크 255.255.255.0
              ───────── ──
              네트워크  호스트
```

- 192.168.0 -> 네트워크를 구분하는 부분
- 10 -> 해당 네트워크 안에서 기기를 구분하는 부분

서브넷 마스크에서

- 1인 비트 -> 네트워크 부분
- 0인 비트 -> 호스트 부분

서브넷 마스크와 IP주소를 비트 AND연산하면 네트워크 주소를 구할 수 있다.

```
IP       192.168.0.10
Mask     255.255.255.0
         ─────────────
AND      192.168.0.0
```

## 왜 필요할까?

PC가 다른 IP로 데이터를 보내려 할 때, 목적지가 같은 네트워크인지 다른 네트워크인지 판단하는데 사용

# DHCP

공유기가 PC에 IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버 정보 등을 자동으로 설정해주는 기능

```
PC: "내가 사용할 IP 주소가 필요해."
           ↓
공유기(DHCP 서버)
           ↓
"192.168.0.105를 사용해.
 서브넷 마스크는 255.255.255.0,
 게이트웨이는 192.168.0.1이야."
           ↓
PC가 해당 네트워크 설정을 사용
```

DHCP가 할당한 IP에는 보통 임대시간(Lease Time)이 있어서 PC는 일정기간 해당 IP를 사용하고, 이후 임대를 갱신할 수 있다.

## IP 고정

- DHCP 예약
  DHCP를 예약해서 공유기에서 IP를 고정할 수도 있다.
  PC의 MAC주소가 `AA-BB-CC-DD-EE-FF`라면 공유기에서 예약할 IP를 : 192.168.0.150 이런식으로 등록해놓으면 PC는 여전히 DHCP 자동 할당을 사용하지만 공유기는 해당 PC에 예약된 192.168.0.150을 할당

- 고정 IP
  PC에서 직접 설정하는 방식, 서브넷 마스크와 게이트웨이도 현재 네트워크에 맞게 지정해야함

고정을 해버리면 IP 주소 충돌이 발생할 수 있다. 그래서 공유기에서 DHCP할당 범위를 확인하고 해당 범위 밖이면서 다른 장치가 사용하지 않는 IP를 선택해야 한다.
