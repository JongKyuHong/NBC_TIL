# 튜토리얼 9번

Ambient Light (주변광)을 추가해서, 빛을 직접 받지 않는 면도 최소 밝기로 보이게 함

```
lightIntensity = saturate(dot(normal, lightDir));
```

- normal : 법선벡터, 물체 표면이 바라보는 방향
- lightDir : 빛이 오는 방향
- dot : 내적 즉, 둘이 얼마나 같은 방향인지 계산
- saturate : 값을 0 ~ 1로 제한

빛 방향과 법선 방향이 비슷하면 1에 가까워져서 밝고, 직각이면 0, 빛 반대편이면 음수가 나오는데 saturate가 0으로 바꾼다. 그래서 확산광만 적용하면 빛 반대편 면은 완전히 검정으로 보이게 된다.

9번은 먼저 모든 픽셀의 기본 색을 앰비언트 라이트로 바꾼다. 주변광은 태양빛이 벽이나 바닥에 반사되어 어두운 곳에도 약하게 퍼지는 상황을 단순화한 조명

# 튜토리얼 10번

스페큘러는 표면색 위에 얹히는 하이라이트라, 텍스처·디퓨즈를 곱한 뒤 더해야 제대로 번쩍입니다. 먼저 섞으면 효과가 묻힘

간단하게 말하면 반사광이다. 9번에서 주변광 + 확산광위에 반사광을 더해서 반짝이게 만듬 실제로 흰색으로 둬서 반짞임

```
주변광(Ambient)  : 모든 면의 최소 밝기
확산광(Diffuse)  : 빛을 향한 정도에 따른 밝기
반사광(Specular) : 카메라와 빛의 위치에 따라 생기는 반짝임

최종색 = (주변광 + 확산광) x 텍스처 색 + 반사광
```

반사광은 카메라의 위치에따라서 보일수도 안보일수도 있다.
빛이 표면에서 반사된 방향으로 카메라가 위치해야 반짝임이 보인다. 그래서 카메라 위치를 셰이더로 보냄

```
N : Normal
L : Light Direction
V : View Direction
```

그래서 이 세개를 본다.

```
lightIntensity = saturate(dot(normal, lightDir));
```

확산광에서는 N과 L을 통해 비교
반사광은 먼저 빛이 표면에 맞고 튕겨 나가는 방향 R이므로

```
reflection = normalize(2.0f * lightIntensity * input.normal - lightDir);
```

그 다음 R과 카메라 방향 V가 얼마나 같은지 비교

```
specular = pow(
    saturate(dot(reflection, input.viewDirection)),
    specularPower
);
```

반사 방향과 카메라 방향이 같으면 dot값이 1에 가까워 반사광이 강하게 보임

## 상수버퍼

```
cbuffer CameraBuffer

    float3 cameraPosition;
    float padding;
};

```
