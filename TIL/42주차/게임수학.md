## 선형 결합

플레이어에게 두 방향이 있다.

Forward=(1,0,0)
Right=(0,1,0)

플레이어가 앞으로 3만큼, 오른쪽으로 2만큼 이동하고 싶다면

3Forward + 2Right = 3(1, 0, 0) + 2(0, 1, 0) = (3, 2, 0)

이게 선형 결합(Linear Combination)이다.

벡터 A, B가 있을때
aA + bB 처럼 각 벡터에 숫자를 곱하고 더하는것을 선형 결합이라고 한다. (a, b는 그냥 스칼라)

---

### Span이란?

주어진 벡터들을 선형 결합해서 만들 수 있는 모든 벡터의 범위

예를들어 A = (1, 0, 0) 하나만 있다고 하자
A에 숫자를 곱하면 2A = (2, 0, 0) , -5A = (-5, 0, 0) 이런식으로 되지만 아무리 해도 (0, 1, 0)은 만들 수 없다. 만들 수 있는건 모두 X축위다.

> 즉, A하나의 Span은 X축이라는 직선

---

### 벡터가 두개/세개 라면?

A=(1,0,0)
B=(0,1,0)

선형결합 aA + bB하면 = (a, b, 0) 이 된다.
따라서 이 두 벡터의 Span은 xy평면 전체가 됨

---

3D 공간 전체를 표현하려면 세 방향이 필요하다.
A=(1,0,0)
B=(0,1,0)
C=(1,1,0)
처럼 세벡터가 모두 같은 평면안에 있으면 안된다.

A=(1,0,0)
B=(0,1,0)
C=(0,0,1)

라면 3D공간 전체를 만들 수 있다.

aA + bB + cC = 0 이라고 했을때 오직 a=b=c=0 일때만 성립한다면 벡터들은 선형 독립이다.

## 선형 종속과 독립

선형 종속은 A에 몇배를 하면 B를 만들 수 있는 경우 A = (1, 0, 0), B = (2, 0, 0) -> B = 2A, A와 B는 선형 종속
독립은 A를 아무리 몇배해도 B를 만들 수 없는 경우 A = (1, 0, 0), B = (0, 1, 0) -> A와 B는 선형 독립

평행하면 종속, 아니면 독립

A = (1, 0, 0), B = (0, 1, 0), C = (1, 1, 0) 에서는 A와 C는 평행하지 않고, B와 C는 평행하지 않지만 C = A + B이다. C는 A와 B로 만들 수 있다 이러면 세 벡터는 선형 종속

### 외적과의 연관

두 벡터 A, B가 평행하면 A x B = 0 이었다.
즉 두 벡터는 선형 종속이다.

## 결론

지금 당장 벡터 공간은 그냥

> 벡터들을 더하고 Scalar를 곱해서 새로운 벡터들을 만들 수 있는 공간

정도로 이해

선형 결합

> 벡터들을 각각 몇 배한 뒤 더하는것

Span

> 그 선형 결합으로 만들 수 있는 모든 벡터의 범위

선형 독립

> 어떤 벡터도 다른 벡터들의 조합으로 대체할 수 없는 상태

세벡터가 서로 선형 독립이면 3D공간 전체를 표현할 수 있다.
세벡터중 하나가 나머지 둘로 만들어 진다면 C = A+B라면 C는 새로운 방향을 추가하지 않음

# 8일차

## Basis

```
X = (1, 0, 0)
Y = (0, 1, 0)
Z = (0, 0, 1)
```

이 세벡터를 통해 P = (3, 2, -1)을 만든다고 치자
P = 3X + 2Y - Z 라고 표현할 수 있다.
X/Y/Z는 3D 공간의 모든 벡터를 표현할 수 있는 재료다.
이런 벡터 집합을 Basis(기저)라고 한다.

### Basis가 되려면 두 조건

3D공간의 Basis가 되려면

1. 3D공간 전체를 Span해야 한다.
   즉 모든 3D 벡터를 만들 수 있어야 한다.0

2. 세 벡터가 선형 독립이어야 한다.
   어떤 축도 다른 축들의 조합으로 만들어지면 안 된다.

세 벡터가 독립이고 3D 공간 전체를 만들 수 있다면 Basis다.

Basis는 꼭 X/Y/Z일 필요가 없다.

3D공간의 Basis가 될 수 있다.

E1 = (1, 0, 0)
E2 = (1, 1, 0)
E3 = (0, 0, 1)

서로 90도가 아니다.
그래도 세 벡터가 독립이고 3D 공간 전체를 만들 수 있다면 Basis다.
Basis의 필수 조건은 독립 + 공간 전체 표현 가능이다.

---

## Basis가 바뀌면 좌표값도 바뀐다

나중에 Local / World Space의 핵심
World 기준 벡터가 P = (3, 2, 1) 라고 했을때

기본 X/Y/Z Basis에서는 P = 3X + 2Y + 1Z 이므로 좌표는 (3, 2, 1)
E1 = (1, 0, 0), E2 = (1, 1, 0), E3 = (0, 0, 1)
P = aE1 + bE2 + cE3로 표현하고 싶다.

계산하면 a(1, 0, 0) + b(1, 1, 0) + c(0, 0, 1) = (a + b, b, c) = (3, 2, 1)
Basis기준 좌표는 (1, 2, 1) a = 1, b = 2, c = 1

### Local / World Space

어떤 캐릭터가 회전해 있다면 캐릭터의 Forward, Right, Up이 World X/Y/Z와 다를 수 있다.
그러면 같은 실제 방향도 World기준좌표, Local기준 좌표가 다르게 표현된다.
여기서 중점은

> 벡터 자체가 달라진게 아니라, 그 벡터를 표현하는 기준 축(Basis)이 달라진 것

### Orthogonal Basis - 직교 기저

Basis의 축들이 서로 모두 90도라면 직교 기저(Orthogonal Basis)라고 한다.

E1​=(2,0,0)
E2​=(0,3,0)
E3​=(0,0,5)

E1​⋅E2​=0
E1​⋅E3​=0
E2​⋅E3​=0

따라서 서로 직교한다. 이런경우 직교 기저

### Orthonormal Basis - 정규직교 기저

X = (1, 0, 0)
Y = (0, 1, 0)
Z = (0, 0, 1)

|X| = |Y| = |Z| = 1

서로 90도이고 길이가 1인 Basis를 정규직교 기저라고 한다.

### 왜 게임에서 정규직교기저가 좋을까?

V = 3Forward + 2Right + 5Up이라고 하자
Forward방향 성분을 알고 싶으면?

내적을 하면 된다 V⋅Forward
전개하면 3(Forward⋅Forward)+2(Right⋅Forward)+5(Up⋅Forward)
정규직교이므로 Forward⋅Forward=1, 나머지는 90도라 0 따라서 V⋅Forward=3

즉, 정규 직교 Basis에서는 x=V⋅Right, y=V⋅Up 등 각축 방향 성분을 굉장히 쉽게 얻을 수 있다.

※ 축 이름과 좌표 대응은 엔진 설정에 따라 다를 수 있으니 지금은 원리만 보면 된다.

---

## Basis가 삐뚤어져 있다면?

A = (1, 0, 0), B = (1, 1, 0)
서로 독립이라 평면의 Basis는 될 수 있다.
하지만 둘을 내적하면 A⋅B=1라 90도가 아니다.

```
      B
     /
    /
   /
--→ A
```

이 상태에서는 각 방향 성분을 단순히 내적만 해서 가져오기가 불편함
그래서 그래픽에서는 가능한 경우 축을

```
서로 수직
+
길이 1
```

로 만들어 사용하는 일이 많다.

### 만약 축들이 처음부터 수직이 아니라면?

A = (1, 0, 0), B = (1, 1, 0)

A의 방향은 유지하면서 B를 A의 수직으로 고치고싶다 여기서는 투영을 사용할 수 있다.

### Gram-Schmidt의 핵심 아이디어

```
      B
     /|
    / |
   /  | 우리가 원하는 부분
--→---+
   A 방향 성분
```

B에서 A방향 성분을 제거하면 된다.
B′=B−projA​(B) = (B ⋅ A) A

앞에서 만든 축 방향으로 튀어나온 성분을 하나씩 제거한다.

---

숫자로 하면
A = (1, 0, 0), B = (1, 1, 0)

B가 A방향으로 가진 성분은 B⋅A=1
projA​(B)는 (B⋅A)A 니까 투영벡터는 (1, 0, 0)
B에서 제거 (1, 1, 0) - (1, 0, 0) = (0, 1, 0)

```
원래
A = (1,0,0)
B = (1,1,0)

직교화 후
A  = (1,0,0)
B' = (0,1,0)

A⋅B′=0 즉 수직이 되었다.
```

---

3개의 벡터에서도
V1=(1,0,0)
V2=(1,1,0)
V3=(1,1,1)

E1​=(1,0,0)
V2에서 E1방향 제거 V2​→(0,1,0)
E2​=(0,1,0)

V3에서는 E1방향, E2방향을 둘다 제거
V3​=(1,1,1)
E3​=(0,0,1)

```
E1 = (1,0,0)
E2 = (0,1,0)
E3 = (0,0,1)
```

서로 수직인 Basis가 만들어짐

### 정규화와 직교화의 차이점

정규화는 각 축의 길이를 1로 만든다.
직교화는 축끼리 90도로 만든다

### 외적으로 Basis를 만드는 경우도 많다.

게임에서는 이미 두 축을 알고 있으면 외적으로 세 번째 축을 만들기도 한다.

```
Forward
Up
```

를 알고있을때 Right = Cross(...) 같은식으로 서로 수직인 방향을 만들 수 있다.
또, 필요하다면 다시 외적해서 다른 축을 보정할수도 있다.

```
Forward
↓
Forward와 Up으로 Right 생성
↓
Right와 Forward로 Up 재계산
```

단, Cross 순서는 좌표계와 원하는 방향에 따라 달라지므로 지금 특정 순서를 무조건 외우지는 않는다.
