# UDP

## UDP 서버는 연결이 끊긴 걸 어떻게 알까?

UDP는 클라이언트의 연결 종료를 자동으로 알려주지 않음
게임 서버에서는 Heartbeat(생존 확인 신호)와 TimeOut(시간 초과)을 사용함

1. 클라이언트가 서버에 주기적으로 생존 신호를 보냄
2. 서버는 마지막으로 패킷을 받은 시간을 기록함
3. 일정 시간 동안 아무 패킷도 오지 않으면 연결이 끊겼다고 판단함

실제 게임에서는 별도의 생존 신호 대신 주기적인 게임 패킷을 연결 확인에 활용할 수 있다.

### 일시적인 패킷 손실과 접속 종료는 어떻게 구분?

패킷이 오지 않는다는 사실만으로는 정확히 구분할 수 없다.
그래서 패킷이 안온다고 바로 접속을 끊지 않고, 일정 시간 기다린 뒤 Timeout으로 판단

- TimeOut을 너무 짧거나 길게 설정하면?

너무짧으면 일시적인 네트워크 지연에도 정상 플레이어를 강제로 끊을 수 있음
너무 길면 실제로 나간 플레이어가 서버에 오랫동안 남아 자원을 차지함

핵심 : UDP에서는 연결 상태를 애플리케이션이 직접 관리하고, 일정 시간 통신이 없으면 접속 종료로 판단 할 수 있음
